## `FEATURED BUILD — NEXAGROW`

### Automated Plant Monitoring & Irrigation System

<img src="https://img.shields.io/badge/HARDWARE-Arduino_Nano_(ATmega328P)_%2B_ESP32-00FF88?style=for-the-badge&labelColor=0D1117" />
<img src="https://img.shields.io/badge/COMMS-MQTT_%7C_SoftwareSerial-00D9FF?style=for-the-badge&labelColor=0D1117" />
<img src="https://img.shields.io/badge/STATUS-ACTIVE_DEVELOPMENT-00FF88?style=for-the-badge&labelColor=0D1117" />

```text
   [ SENSORS ]        [ ARDUINO NANO ]         [ ESP32 ]           [ WEB DASHBOARD ]
   soil · water   ───►   slave node    ── SW ──►  master   ── MQTT ──►  live monitor +
   light · temp        (firmware-tight)   Serial     node               schedule control
```

**Engineering highlights**
- Firmware hand-tuned for the Nano's tight RAM/Flash budget — `String` class replaced with fixed `char[]` buffers, `F()` macros for debug text, zero-copy JSON parsing
- Bidirectional plant-phase sync (`faseVegetatif`) across Arduino ↔ ESP32 ↔ web dashboard, with EEPROM/NVS persistence so schedules and phase survive a reboot
- ESP32-as-master / Arduino-as-slave architecture over SoftwareSerial
- Full brand identity shipped alongside the code: logo system (icon mark, wordmark, dark badge, PNG exports), water-droplet + leaf-sprout + circuit motif
